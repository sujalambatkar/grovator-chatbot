# What it is
The Debug Console helps you find mistakes in your program. Open it with the bug button next to Run.

# Using it
Add a say block with a variable or a sensor value and the console prints it each time the block runs. Turn on Step Mode to run one block at a time: the running block is highlighted. The Variable Watcher shows the live value of every variable.

# Typical use
If your robot turns the wrong way, use Step Mode to see which block runs when. If a counter looks wrong, watch the variable change in the watcher.
