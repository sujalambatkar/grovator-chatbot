# Goal
Understand what the Internet of Things is and connect your IoT kit for the first time.

# What is IoT
An IoT device has a sensor to notice something, a controller to decide what to do, and a way to share data. A smart thermostat, a fitness band and a streetlight that turns on at dusk are all IoT devices.

# Steps
1. Connect the controller board to the computer with the USB cable.
2. Open the IoT subject and press Connect Kit.
3. Wait for the green status light.
4. Open the workspace and drag the when green flag clicked block.
5. Add a display block that says Hello IoT and press Run.

# Blocks you will use
when green flag clicked, display text, wait seconds.

# Common mistakes
Forgetting the green status light means the kit is not connected. If the display stays blank, check that your program starts with an Events block.

# Quiz
Question 1: Name the three parts of an IoT device. Answer: a sensor, a controller and a way to share data. Question 2: What colour is the status light when the kit is connected? Answer: green.
