# Course overview
IoT Foundations is an 8-week course for Grades 6 to 8. Students use the IoT kit and block coding to build small smart devices that sense the world, make decisions and send data to the Govator dashboard. IoT means Internet of Things: everyday objects that sense and share data.

# What you will learn
You will learn what IoT is, how to read the temperature, light and motion sensors, how to control the LED and buzzer, how to make decisions with if and else blocks, and how to send sensor data to a live graph. You finish by building a Smart Room Alert.

# Modules and lessons
Module 1 is Hello IoT with Lesson 1 What is IoT. Module 2 is Sensing the World with Lesson 2 Temperature Sensor, then the light sensor and motion sensor activities. Module 3 is Taking Action with Lesson 3 LED and Buzzer, then the Smart Night Light activity. Module 4 is Sharing Data with Lesson 4 Send Data to the Dashboard and reading the graph. Module 5 is the final project, Smart Room Alert.

# Kit you need
The IoT kit: controller board, temperature sensor, light sensor, motion sensor, LED, buzzer, small display and connecting wires. If you have no kit, use the Simulator.

# How you are assessed
Each lesson ends with a two-question quiz. You pass the course when you complete at least 80 percent of the lessons and score at least 60 percent on the final project. The project rubric gives points for a working sensor, a working decision, sending data and a clear explanation.
