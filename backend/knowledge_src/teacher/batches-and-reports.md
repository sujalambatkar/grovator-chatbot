# Your batches
Teachers see only the batches assigned to them. Open Batches from the menu to see each batch with its students and subject. You cannot see batches belonging to other teachers.

# Student reports
Open a batch, then pick a student to view the report. The report shows lessons completed, activity scores and time spent for each subject. Use the Download button to export the batch report as a PDF.

# Resetting a student password
Open the student profile and press Reset Password. A temporary password is shown once. Share it with the student privately.

# Class schedule
The Schedule page lists upcoming sessions for each batch. Click a session to see the lesson plan and the kits needed. Remind students to charge the robotics battery packs before the session.
