# What control blocks do
Control blocks are orange. They decide when and how often other blocks run.

# wait seconds
Pauses the program for the number of seconds you type. Useful so readings are easy to see and so the robot has time to finish a move.

# repeat
Runs the blocks inside it a fixed number of times. Repeat 4 times with move forward and turn right 90 draws a square.

# forever
Runs the blocks inside it again and again until you press Stop. Use it for sensors that must be checked all the time.

# if and if else
If runs its blocks only when the condition is true. If else lets you choose between two actions, for example: if distance is less than 10 then stop all motors, else move forward.

# wait until
Pauses until a condition becomes true, such as wait until button pressed.

# repeat until
Repeats the blocks until a condition becomes true, such as repeat until distance is less than 10.

# stop this program
Ends the program immediately.
