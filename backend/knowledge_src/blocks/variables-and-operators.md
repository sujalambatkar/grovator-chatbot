# Variables
Variables are red blocks. A variable is a named box that stores a value so your program can remember it. Make one with Make a Variable, then use set score to 0 to give it a starting value and change score by 1 to add to it. Variables are useful for counting, timing and keeping scores.

# Operators
Operators are green blocks that calculate. The plus, minus, times and divide blocks do maths. The greater than, less than and equals blocks compare two values and give true or false. The and, or and not blocks combine conditions, for example temperature greater than 30 and light level less than 20.

# random between
Gives a random whole number between two numbers. Use random between 1 and 6 to roll a dice.

# Tip
Give variables clear names like alarms or laps. A clear name makes your program easy to read.
