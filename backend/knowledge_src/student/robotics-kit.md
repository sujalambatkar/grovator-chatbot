# What is in the robotics kit
The Robotics Foundation kit has a robot controller, two drive motors with wheels, a distance sensor, a line sensor, a battery pack and a chassis frame. You build the robot and program it with blocks.

# Powering and connecting
Insert the batteries and switch the controller on. Connect it to the computer by USB and press Connect Kit in the Robotics Foundation subject. The motors only move when the battery pack is switched on, so check the switch if the robot does not move.

# Driving the robot
Use Motion blocks such as "move forward for 2 seconds" and "turn left 90 degrees". Start with short moves and test often. Place the robot on the floor, not on the table edge.

# Using the distance sensor
The distance sensor measures how far an object is in centimetres. Use it with an if block so the robot stops or turns when something is close.

# Line following
The line sensor sees dark and light surfaces. Use if-else: if the sensor sees the line, go straight; else turn slightly. Repeat forever to follow a black line on white paper.

# Robot not working
Check the battery switch, the USB connection and that the motor ports in the blocks match the cables. If the robot drifts to one side, check both wheels are tight.
