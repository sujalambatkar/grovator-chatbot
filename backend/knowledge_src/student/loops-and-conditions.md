# Repeat loops
Use the "repeat" block when you want to do something many times. Put the blocks you want to repeat inside the repeat block, and type how many times. For example, repeat 4 times: move forward, turn right. This draws a square.

# Forever loops
The "forever" block keeps running its blocks until you press Stop. Use it for robots that must keep checking a sensor.

# If and if-else
The "if" block runs its blocks only when a condition is true. Use if-else to choose between two actions. For example: if distance is less than 10, then stop; else move forward. This stops a robot before it hits a wall.

# Variables
A variable is a named box that stores a value. Use "set score to 0" to create it and "change score by 1" to add to it. Variables are useful for counting, timing and scores.
