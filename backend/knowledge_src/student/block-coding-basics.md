# What is block coding
Block coding lets you build programs by snapping colourful blocks together instead of typing code. Each block is one instruction. Blocks stack from top to bottom and the computer runs them in that order.

# The workspace
The block workspace has three areas. The block palette on the left holds all the blocks grouped by colour. The coding area in the middle is where you drag and snap blocks. The run panel on the right has the Run button and shows the output or the simulator.

# Block categories
Events blocks start your program, for example "when green flag clicked". Motion blocks move a robot or sprite. Sensor blocks read values such as distance or light. Control blocks hold loops and conditions such as repeat and if-else. Variables blocks store numbers or text that your program can remember.

# Running and saving
Press the Run button to start your program. Press Stop to end it. Your project saves automatically, and you can also press Save to be sure. You can reopen saved projects from My Projects.

# Fixing mistakes
If your program does not work, check that every stack begins with an Events block. Look for blocks that are not snapped together; loose blocks do not run. Drag unwanted blocks to the palette to delete them.
