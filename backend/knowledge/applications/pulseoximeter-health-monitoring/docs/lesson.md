# Module objective
By the end of this module students will explain the use of an oximeter, explain the working principle of an oximeter and a pulse sensor, demonstrate how to monitor pulse and oxygen level in human blood, and build a pulse meter and oximeter that shows readings.

# The challenge
In the Covid pandemic time, we want to measure the health of people by checking their oxygen levels. To make it simple for patients, we want to show with visual indicators whether the levels are satisfactory, good or need attention.

# The 5 step process
1. Understand the problem. 2. Find a solution using appropriate technology. 3. Build the application logic. 4. Connect the physical components (Circuit Designer). 5. Write the software program using block programming (Block Designer).

# Fundamental building blocks of IoT applications
Input: the pulse oximeter detects the pulse and oxygen level and sends the signal to the IoT gateway. Processor: the IoT gateway (ESP32 kit). Output: LEDs glow based on the pulse sensor reading. Notification: the actual reading shows on a smartphone screen through the internet cloud.

# How the pulse oximeter works
The sensor consists of a super bright red LED and a light detector. The LED needs to be super bright so that the maximum light spreads through the finger and is detected by the detector. When the heart pumps a pulse of blood through the blood vessels, the finger becomes slightly more opaque and less light reaches the detector. With each heart pulse the detector signal changes. This change is converted into an electrical pulse, which is amplified. A LED on the sensor blinks on each heartbeat. Science concept: reflection and refraction of light.
